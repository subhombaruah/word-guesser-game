# Word Guesser Game 💭
A simple word guessing game made using **Python** 💎

### Libraries used:
1. requests (to integrate the use of an [API](https://random-word-api.vercel.app/) that fetches random words from its database)
2. random (to generate random length for word fetching, random blank spacing indexes, random indexes for hint.

### How to play ❔

* There are two game modes, easy and hard. Easy has 2 hidden letters and hard has 3 hidden letters.
* You need to guess the word in **one try** but you can make your job easier by getting 1 (and only 1) hint! 🙇
* You can't get 2 hints consecutively for a word
* If you get a word wrong, _the game is **over**_
* You can see stats like *high Score, games played* etc.
